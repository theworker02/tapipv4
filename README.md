# tapipv4

Tap lightweight ipv4 statistics from stdin samples.

**Site:** https://theworker02.github.io/tapipv4/

## Install / run

```bash
git clone https://github.com/theworker02/tapipv4.git
cd tapipv4
node src/cli.js
node --test
```
